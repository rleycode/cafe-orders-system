# CafeOrders
Веб-приложение для автоматизации учета и обработки заказов в кафе. 

## Цели системы
1. **Исключение ошибок** официанта при ручном подсчете итоговой суммы заказа.
2. **Сокращение времени** передачи заказа от официанта к повару благодаря электронной очереди.
3. **Контроль состава блюд** и аллергенов прямо при приеме заказа.
4. **Автоматизация учета** и подсчета выручки за выбранный период.

## Роли
* **Официант:** Принимает заказы для столов, добавляет и удаляет позиции, вносит чаевые и закрывает заказы после оплаты.
* **Повар:** Просматривает текущую очередь заказов и отмечают их готовность.
* **Администратор:** Обладает полными правами официанта, а также управляет меню, столами, персоналом и формирует отчеты по выручке.

## Возможности
В проекте реализованы следующие основные возможности:
* просмотр меню с подробным составом блюд и информацией об аллергенах;
* создание заказа с привязкой к конкретному столу;
* добавление и удаление позиций заказа с автоматическим пересчетом итоговой суммы;
* просмотр и управление электронной очередью заказов для кухни;
* отслеживание и изменение статусов заказов в реальном времени;
* закрытие заказов с учетом чаевых и оплаты;
* управление справочниками блюд, столов и сотрудников (администрирование);
* выгрузка аналитических отчетов по выручке за выбранный период в формате **CSV**.
